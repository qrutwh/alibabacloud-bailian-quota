## 免费额度的五条细则，不看容易踩坑

免费额度不是一笔笼统的赠送，规则可以概括成五条：90 天有效、按模型独立、不会自动切换、主子账号共享、只抵扣实时推理。官方文档写得很细，但不少教程只提一句「新用户送额度」就完了，下面这几条直接影响你怎么用：

1. **有效期 90 天**，从开通百炼、模型发布或模型申请通过之日（以较晚者为准）起算。额度有效期内用不用都照常计时，到期后剩余部分自动作废，不补发、不延期、不重置。
2. **每个模型独立额度，互不共享**。带日期后缀的快照版本（比如 qwen-max-2026-05-17）和不带日期的最新版本（qwen-max）算两个独立模型，各自有独立额度。
3. **额度用完不会自动切换模型**。代码里写的是 qwen-max，它的额度耗尽后，哪怕 qwen-plus 还剩几百万 Token，系统也不会帮你切过去——要么调用直接被停（开了用完即停），要么超出部分按量计费（已认证且没开）。想用别的模型额度，得手动改 model 参数。
4. **主账号和 RAM 子账号共享同一份额度**。主账号用了 10 万、子账号用了 20 万，剩余就是 70 万。
5. **只抵扣实时推理调用**。OpenAI 兼容-Batch（文件输入）产生的费用不在免费额度覆盖范围内；ASR 类模型还要先在业务空间逐一开通权限，才能调用并消耗额度。

第 3 条最容易出事故：项目跑了一半，模型额度耗尽，如果没有任何保护设置，账单就开始按量走人了。所以下一节的防扣费设置，建议开通当天就做。

## 开通后怎么调通第一个模型

拿到 API Key 之后，调用方式和 OpenAI 基本一致。官方文档当前给出的北京地域 Python 示例如下：

python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.getenv("DASHSCOPE_API_KEY"),
    base_url="https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1",
)
completion = client.chat.completions.create(
    model="qwen3.8-max",
    messages=[{'role': 'user', 'content': '你是谁？'}]
)
print(completion.choices[0].message.content)


三处需要留意：

- base_url 里的 `{WorkspaceId}` 要替换成你的业务空间 ID，不同地域的 base_url 不通用。官方目前列出的地域包括华北2（北京）、新加坡、中国香港、德国（法兰克福）、日本（东京）和美国（弗吉尼亚）。
- 如果你参考的网上教程 base_url 长得和上面不一样，调用报错时先检查业务空间 ID 有没有替换，并以百炼控制台内文档给出的当前格式为准。
- 已经在用 OpenAI SDK 的老项目，理论上只需要改 API Key、base_url 和 model 三个值就能迁移。

模型怎么选，官方文档的定位很清楚：qwen3.8-max 是当前效果最好的一档，适合复杂多步任务；千问 Plus 在效果、速度和成本之间比较均衡，是多数场景的推荐选择；千问 Flash 高性价比、低延迟，跑简单任务足够。除了千问系列，DeepSeek、Kimi、GLM 等第三方模型也能直接调，不过文档注明 DeepSeek 在模型广场的在线体验目前仅北京地域支持。

## 担心扣费？开通当天就该做的几项设置

先把最关键的事实说清楚：百炼没有「自动扣费」开关这回事，平台按量付费，不调用就不收钱。真正让人意外的，是免费额度耗尽之后的行为，而这取决于你的账号状态：

- **未完成实名认证**：系统默认强制开启「用完即停」，开关不可见也无法操作。额度用完后调用会返回 HTTP 403（错误码 `AllocationQuota.FreeTierOnly`），不会继续扣费。
- **已认证、未开「用完即停」**：额度耗尽后正在进行的调用不会中断，超出部分按控制台价格按量扣费，可能把账户扣成欠费。注意欠费状态下，即使其他模型还有免费额度也调不了。
- **已认证、开了「用完即停」**：额度耗尽即停止响应，想继续用需要手动关闭这个开关。

「用完即停」可以在免费额度页面按单个模型开，也能批量开或一键开启所有模型。两点提醒：配置生效需要时间（官方建议等待约半小时），生效期间的调用可能照常计费；官方文档同时提示，生产环境不建议开启，免得额度耗尽导致服务中断——保护开关和业务连续性之间要自己权衡。

想更彻底地阻断调用，直接删除所有 API Key，并排查应用里的定时任务和后台进程，从源头停掉。余量方面也有兜底：额度降到 20% 或完全耗尽时，系统会通过短信、站内信和邮件通知，还可以再配置预算管理和余额预警。👉 [到免费额度页开启「用完即停」](https://bailian.console.aliyun.com/cn-beijing/costing-balance/free-quota?userCode=5eqf8rny)

## 常见问题

**开通百炼之后放着不用，会扣钱吗？**

不会。开通本身免费，只有实际发生调用、微调或部署才计费，也不存在会自动开启的付费项目。

**免费额度用完之后，会自动从我账户扣费吗？**

分三种情况：未实名认证的账号无法继续调用，不会扣费；已认证且开启「用完即停」的账号，额度耗尽后停止响应；已认证但没开开关的账号，会继续按量扣费并可能欠费。

**领免费额度需要实名认证吗？**

领取和使用都不需要。但额度用完后想按量付费继续用，就要先完成认证并充值，支持支付宝、银联在线支付、网银等方式。

**我的数据会被拿去训练模型吗？**

官方文档明确：使用按量付费 API 和 Token Plan 团队版时，阿里云不会将你的数据用于模型训练，构建应用或训练模型时传输的数据均经过加密处理。
